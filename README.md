# Mordant d-Moll

**La nota inicial de la *Toccata und Fuge d-Moll* (BWV 565) de Bach en 22 representaciones distintas.**

→ **[jlmirallesb.github.io/mordant_d_moll](https://jlmirallesb.github.io/mordant_d_moll/)**

---

Un mordente. Una nota. 22 maneras de escribirla: WAV, FLAC, MP3, forma de onda, espectrograma, manuscrito, PDF escaneado, PDF vectorial, PNG, SVG, MIDI literal e interpretado, rollo de pianola, MSCZ, MXL, MusicXML, LilyPond, ABC, MEI, Humdrum/**kern, MuseData y braille musical.

Cada representación incluye una breve explicación, sus metadatos técnicos y un enlace de descarga del archivo.
